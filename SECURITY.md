# Security Policy

## Supported version

FreshTrack is currently operated as one live web application. Security fixes are applied to the latest version on the `main` branch; older revisions are not supported deployments.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `masoncao7@gmail.com`. Include the affected route or component, reproduction steps, impact, and any suggested mitigation. Do not include real user data in a report.

Please do not open a public issue, access data that is not yours, degrade the service, or run automated high-volume tests against production. Acknowledgement is targeted within 72 hours, followed by an impact assessment and remediation timeline when the report is reproducible.

There is currently no paid bug-bounty program.
