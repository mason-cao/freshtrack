Interaction Details

Swipe Gestures (Mobile)
Framer Motion drag="x" on each card. Swipe right → green "Used" reveal. Swipe left → terracotta "Wasted" reveal. Spring snap-back on release below threshold.
Action Buttons (Desktop)
Rounded icon buttons — green checkmark (Used) and terracotta trash (Wasted). Hover scales with spring physics. Confirmation still via alert dialog.
Search
Client-side filter. Debounced input filters items by name. Results update with staggered fade animation.
Filter Chips
Pill-shaped toggles. Active chip uses filled sage background. Framer Motion layoutId on active indicator for smooth sliding.
